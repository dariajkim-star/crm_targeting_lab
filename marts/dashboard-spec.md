아래 9개 필드만 워크북의 필드 목록·드롭다운에 노출한다. 표에 없는 마트 컬럼은 노출하지 않는다.

| 노출 필드 | 탭 | 용도 |
|---|---|---|
| `CLIENTNUM` | 2 | 행 식별(툴팁·상세). 집계 금지(스키마 용도/금지 칸). |

### 숨김 필드 (데이터 원본에서 hide 처리 — 필드 목록 비노출)

- **`churn_score`** — **어떤 탭·시트·드롭다운에도 노출하지 않는다.** 근거: 화면에 필요한 시트가
  없고(분면은 `quadrant_official`, 기준선은 `threshold_official_risk`가 담당), 노출 시
  `churn_prob_calibrated`와 나란히 떠 금액 산식 오선택으로 **총합 +19.0% 부풀림**(3-2 실측:
  1,730,042 vs 정답 1,454,088). 감사가 필요하면 마트 CSV와 스키마 문서를 직접 본다 —
  **층 분리: 마트=감사 가능성(컬럼 유지), 화면=오용 방지(숨김)**.

## 탭 구성 (4탭)

### 탭1 「타게팅 2×2」 — 공식

- **시트 1-1 분면 산점도**: x=`churn_prob_calibrated`, y=`customer_value`(로그 스케일 허용 —
  표시 스케일이며 값 변형 아님), 색=`quadrant_official`(4색 고정). 기준선: x=`threshold_official_risk`,
  y=`threshold_official_value` 상수선 2본 + 값 라벨.
- **시트 1-2 분면 요약표**: `quadrant_official`별 인원·`expected_saving` 합. **검산 기대값**(마트
  실측, 워크북 제작 시 대조): low_cost_keep 4,624 · accept_churn 2,971 · watch 2,089 · save_first 443,
  총합 ≈ 1,454,088.
- 캡션: "분면·임계값은 Python 산출 공식값(마트 컬럼). 화면은 표시만 한다."

### 탭2 「캠페인 우선순위」 — 공식 + 시나리오

- **시트 2-1 (공식) 우선순위 리스트**: `target_priority` 오름차순 정렬, `expected_saving` 막대,
  툴팁에 `CLIENTNUM`·`quadrant_official`. 캡션: "expected_saving은 성공률 0.30·건당 비용 5.0
  **가정**(정책가정, 실측 아님)의 산출이다."
- **시트 2-2 (시나리오) 예산 선택**: 시트 제목 **`[시나리오] 예산별 캠페인 선택`**. 예산 파라미터
  `[budget]`(양수, 기본 2,500) 하나만 받는다. 계산필드:

  ```
  campaign_selected_scenario =
      ([target_priority] <= FLOOR([budget] / 5.0)) AND ([expected_saving] > 0)
  ```

  이 산식은 `mart_customers.schema.md`의 **AD-12 고정 정의**(`campaign_selected` =
  `target_priority ≤ 예산이 사는 접촉 수` AND `expected_saving > 0`, 산출 단일 소유
  `select_within_budget`)를 그대로 옮긴 것이다 — **비탑재 정의의 시각화이지 공식 컬럼의
  재계산이 아니다**(`campaign_selected`는 마트 컬럼이 아니고, 예산은 시나리오 입력이다 — 4-1b D1).
  `5.0`은 `COST_PER_CONTACT` **정책가정** — 캡션에 라벨 필수. 선택 인원·선택분 절감 합을 함께 표시.

### 탭3 「세그먼트 프로필」 — 공식

- **시트 3-1 세그먼트 구성**: `segment_id`(1–4)별 인원·`customer_value` 중위·`quadrant_official`
  구성비 누적막대.
- **요인·리텐션 액션 캡션 규약(A8)**: 이 탭에서 이탈 요인·액션을 언급할 때는 **텍스트 캡션만**
  허용한다(SHAP 수치·차트 반입 금지 — SHAP 데이터는 gitignored `data/churn_shap.parquet`로 마트·
  공개면에 없다). 캡션 출처는 `docs/implementation-artifacts/churn-drivers-actions-1-7.md`이며,
  요인을 언급하는 **모든** 캡션에 다음 두 문구를 병기한다:
  1. **"요인은 모델이 위험 점수를 매길 때 그렇게 판단한 근거이지 인과가 아니다"** (SHAP≠인과)
  2. **"액션은 실측 아닌 제안"**
  이 경고 없이 요인을 표시하는 시트는 **사양 위반**이다.

### 탭4 「LTV 방법론 데모」 — 동결 스텁

  시트·필드 매핑은 4-2 해동 시 이 문서에 추가한다.
- 스텁 상태에서도 유효한 원칙: 해동되더라도 이 탭은 **별도 데이터 원본**으로 연결하며, 고객 마트와
  결합됐다는 인상을 주는 어떤 시각 요소도 두지 않는다(AD-2).

## 시나리오 뷰 규약 (AD-3 검사 가능 4항목 — 체크리스트)

시나리오 시트(현재 2-2 하나)는 다음 4항목을 **전부** 지킨다:

1. 시트 제목이 **`[시나리오] `** 로 시작한다.
2. **공식 뷰와 다른 탭**에 두지 않는다면(같은 탭 2 안에 공존) 시트 배치로 구분하되, 대시보드
   레이아웃에서 공식 시트와 **시각적으로 분리**된 영역에 둔다.
3. **다른 배경색**을 적용한다(공식 시트 = 흰색, 시나리오 시트 = 회색 계열).
4. **현재 값과 공식 값을 병기**한다 — 예산 파라미터의 현재값과 함께, 공식 임계값
   (`threshold_official_risk`·`threshold_official_value`)이 화면에 항상 보인다.

- 시나리오 계산필드 이름은 **`_scenario` 접미**를 갖는다.
- **`_official` 컬럼을 재계산하는 계산필드를 만들지 않는다** — `quadrant_official`을 다시 긋거나
  `threshold_official_*`를 다시 구하는 필드는 이름과 무관하게 금지.

## 금지 조항 (기계 검증 대상)

1. **마트 조인 금지**: 두 마트를 조인하는 계산필드·관계·블렌드를 만들지 않는다(AD-2). 탭4가
   해동되어도 원본은 물리 분리 유지.
2. **`_official` 재계산 금지**: 공식 컬럼이 답하는 질문(분면·임계값·기대절감·순위)을 화면
   계산필드로 다시 계산하지 않는다(AD-3).
3. **risk_quantile annex 반입 금지**: 3-4의 risk_quantile annex(0.70/0.80 분면 구성)는 대시보드에
   **탭·시트·파라미터 어느 형태로도 싣지 않는다.** 시나리오 파라미터는 성공률·비용(3-4 코어 2D)
   계열만 허용한다 — 분면 정의를 화면에서 흔들면 "공식 2×2는 하나"(3-1·AD-12)가 화면에서 물러진다.
   (annex 자체는 `sensitivity-report` 계열 세션 산출물에 남는다 — 코드 층 계약은 3-4가 테스트로
   보장, 화면 층 계약이 이 조항이다.)
