## 노출 필드 (단일 출처 — 테스트가 이 표를 파싱한다)

아래 9개 필드만 워크북의 필드 목록·드롭다운에 노출한다. 표에 없는 마트 컬럼은 노출하지 않는다.
**탭 칸은 본문 시트 명세와 1:1 정합**이다(테스트가 탭 번호 유효성을 검사한다).

| 노출 필드 | 탭 | 용도 |
|---|---|---|
| `CLIENTNUM` | 2, 5 | 행 식별(툴팁·상세). 집계 금지(스키마 용도/금지 칸). |
| `segment_id` | 3 | 세그먼트 그룹핑(명목 척도 — 크기 비교 무의미). |

| `churn_prob_calibrated` | 1 | 위험 축 표시(보정 확률). 금액 산식의 확률 입력이기도 하다 — 분면 컷 재계산 금지. |

| `threshold_official_risk` | 1, 5 | 공식 위험 컷 기준선(상수선) + 시나리오 탭 병기(AD-3 ④). |
| `threshold_official_value` | 1, 5 | 공식 가치 컷 기준선(상수선) + 시나리오 탭 병기(AD-3 ④). |
| `expected_saving` | 1, 2, 5 | 기대절감(가정 라벨 필수: 성공률 0.30·비용 5.0 = 정책가정, NFR1). |
| `target_priority` | 2, 5 | 접촉 우선순위, **1-base(1..n, 1이 최우선)**. 순위≠추천(스키마 금지 칸). |

### 숨김 필드 (데이터 원본에서 hide 처리 — 필드 목록 비노출)

- **`churn_score`** — **어떤 탭·시트·드롭다운에도 노출하지 않는다.** 근거: 화면에 필요한 시트가
  없고(위험 축 표시와 확률 입력은 `churn_prob_calibrated`, 분면은 `quadrant_official`, 기준선은

## 탭 구성 (공식 4탭 + 시나리오 1탭)

### 탭1 「타게팅 2×2」 — 공식

원본: `marts/mart_customers.csv`

- **시트 1-1 분면 산점도**: x=`churn_prob_calibrated`, y=`customer_value`(로그 스케일 허용 —
  표시 스케일이며 값 변형 아님), 색=`quadrant_official`(4색 고정). 기준선: x=`threshold_official_risk`,
  y=`threshold_official_value` 상수선 2본 + 값 라벨.
- **시트 1-2 분면 요약표**: `quadrant_official`별 인원·`expected_saving` 합.
- 캡션: "분면·임계값은 Python 산출 공식값(마트 컬럼). 화면은 표시만 한다."

### 탭2 「캠페인 우선순위」 — 공식

원본: `marts/mart_customers.csv`

- **시트 2-1 우선순위 리스트**: `target_priority` 오름차순 정렬, `expected_saving` 막대, 툴팁에
  `CLIENTNUM`·`quadrant_official`·`customer_value`. 캡션: "expected_saving은 성공률 0.30·건당
  비용 5.0 **가정**(정책가정, 실측 아님)의 산출이다."

### 탭3 「세그먼트 프로필」 — 공식

원본: `marts/mart_customers.csv`

- **시트 3-1 세그먼트 구성**: `segment_id`(1–4)별 인원·`customer_value` 중위·`quadrant_official`
  구성비 누적막대.
- **요인·리텐션 액션 캡션 규약(A8 — 전역 규약의 본문, 머리말 참조)**: 요인·액션을 언급할 때는
  **텍스트 캡션만** 허용한다(SHAP 수치·차트 반입 금지 — SHAP 데이터는 gitignored
  `data/churn_shap.parquet`로 마트·공개면에 없다). 캡션 출처는
  `docs/implementation-artifacts/churn-drivers-actions-1-7.md`이며, 요인을 언급하는 **모든**
  캡션에 다음 두 문구를 병기한다:
  1. **"요인은 모델이 위험 점수를 매길 때 그렇게 판단한 근거이지 인과가 아니다"** (SHAP≠인과)
  2. **"액션은 실측 아닌 제안"**
  이 경고 없이 요인을 표시하는 시트는 **사양 위반**이다.

### 탭4 「LTV 방법론 데모」 — 동결 스텁

- **epic-2 무기한 동결로 `mart_ltv_demo.csv`가 존재하지 않는다.** 이 탭은 자리만 예약한다 —
  시트·필드 매핑은 4-2 해동 시 이 문서에 추가한다.
- 스텁 상태에서도 유효한 원칙(AD-2 비결합): 해동되더라도 이 탭은 **별도 데이터 원본**

  두지 않는다.

### 탭5 「[시나리오] 예산별 캠페인 선택」 — 시나리오 전용 탭

원본: `marts/mart_customers.csv` (탭1~3과 같은 원본 — 별도 탭인 이유는 AD-3 ②)

- **시트 5-1 예산 선택**: 시트 제목 **`[시나리오] 예산별 캠페인 선택`**. 예산 파라미터 `[budget]`
  하나만 받는다. 계산필드:

  ```
  campaign_selected_scenario =
      ([target_priority] <= FLOOR([budget] / 5.0)) AND ([expected_saving] > 0)
  ```

  이 산식은 `mart_customers.schema.md`의 **AD-12 고정 정의**(`campaign_selected` =
  `target_priority ≤ 예산이 사는 접촉 수` AND `expected_saving > 0`, 산출 단일 소유
  `select_within_budget`)를 옮긴 것이다 — **비탑재 정의의 시각화이지 공식 컬럼의
  재계산이 아니다**(`campaign_selected`는 마트 컬럼이 아니고, 예산은 시나리오 입력이다 — 4-1b D1).
  `5.0`은 `COST_PER_CONTACT` **정책가정** — 캡션에 라벨 필수. `target_priority`는 1-base이므로
  `<=`가 정확히 "예산이 사는 인원"을 고른다. 선택 인원·선택분 절감 합을 함께 표시.
- **파라미터 허용 값(필수 설정)**: 데이터 타입 **정수**, **최소 0**, 단계 500 권장, 기본 2,500.
  `budget=0`이면 선택 0명 — **빈 시트가 정상 동작**이며 캡션이 "예산 0 = 빈 캠페인"을 말해야
  한다(Python 경로는 음수 예산을 오류로 거부하므로, 화면은 최소 0 제한으로 음수를 원천 차단).
- **코드와의 동치 한계(정직 각주)**: Python `select_within_budget`는 부동소수 경계 보정
  `_BUDGET_TOL`을 두지만 위 산식에는 없다 — 예산이 5의 배수 **정수**인 한 괴리 0이며, 파라미터
  허용 값 설정(정수·단계 500)이 그 전제를 강제한다. 임의 실수 예산을 허용하면 경계값에서 코드와
  1명 차이가 날 수 있다.
- **AD-3 4항목 적용**(아래 규약 절): 이 탭의 배경색을 공식 탭과 다르게 하고,
  `threshold_official_risk`·`threshold_official_value`를 상수 텍스트로 **항상 병기**한다.

## 시나리오 뷰 규약 (AD-3 검사 가능 4항목 — 체크리스트)

시나리오 시트(현재 5-1 하나)는 다음 4항목을 **전부** 지킨다:

1. 시트 제목이 **`[시나리오] `** 로 시작한다.
2. **공식 뷰와 다른 탭**에 둔다 — 시나리오 시트는 공식 4탭 밖의 전용 탭(탭5)에만 존재한다.
3. **다른 배경색**을 적용한다(공식 탭 = 흰색, 시나리오 탭 = 회색 계열).
4. **현재 임계값과 공식 임계값을 병기**한다 — 예산 파라미터의 현재값과 함께, 공식 임계값
   (`threshold_official_risk`·`threshold_official_value`)이 화면에 항상 보인다.

- 시나리오 계산필드 이름은 **`_scenario` 접미**를 갖는다.
- **`_official` 컬럼을 재계산하는 계산필드를 만들지 않는다** — `quadrant_official`을 다시 긋거나
  `threshold_official_*`를 다시 구하는 필드는 이름과 무관하게 금지.

## 금지 조항 (기계 검증 대상)

1. **마트 조인 금지**: 두 마트를 조인하는 계산필드·관계·블렌드를 만들지 않는다(AD-2). 탭4가
   해동되어도 원본은 물리 분리 유지.
2. **`_official` 재계산 금지**: 공식 컬럼이 답하는 질문(분면·임계값·기대절감·순위)을 화면
   계산필드로 다시 계산하지 않는다(AD-3).
3. **risk_quantile annex 반입 금지**: 3-4의 risk_quantile annex(0.70/0.80 분면 구성)는 대시보드에
   **탭·시트·파라미터 어느 형태로도 싣지 않는다.** **분면 정의를 바꾸는 파라미터(risk_quantile
   등)는 금지**이며, 시나리오 파라미터로 허용되는 것은 **예산·성공률·비용 계열**(캠페인 가정 축 —
   3-4 코어 2D + 4-1b 예산 정의)뿐이다 — 분면 정의를 화면에서 흔들면 "공식 2×2는 하나"
   (3-1·AD-12)가 화면에서 물러진다. (annex 자체는 세션 산출물에 남는다 — 코드 층 계약은 3-4가
   테스트로 보장, 화면 층 계약이 이 조항이다.)
