# Spike 4 · 사전등록 — 무형자산 잔차 개별 검증

- **일자**: 2026-07-29
- **성격**: **측정 전 작성·커밋.** git 이력이 순서를 증명한다(스파이크2·3-V 방식 계승).
- **복명복창**: 표준 XBRL 금액이 안 잡히는 회사를 찾아 ①진짜 누락 ②다른 곳 기재 ③애초에 0으로
  구분하고, **정상화하면 기업가치·재무비율·투자자 판단이 달라지는가**에 답한다.

---

## 1. 대상과 걸린 것

**무형자산 잔차 26건 / 회사 23곳** (4개 분기, `FiniteLivedIntangibleAssetsGross` 또는
`…AccumulatedAmortization` 중 하나만 있고 순액 계열 태그 전무).

> **정정**: 종전 "16곳"은 2025Q1 단일분기 수치다. 4개 분기 기준은 26건/23사.

**표본 추출 없음 — 전수 검증.** n=23은 전부 볼 수 있는 규모이므로 무작위 시드가 불필요하다.

**걸린 것**: 세 번째이자 **마지막 미검증 개념**이다. 리스 0/12 · SBC 0/11에 이어 여기서도 d=0이면
**세 개념 전멸**이며, 프로젝트는 "진짜 누락은 극히 드물다"를 결론으로 삼는 국면에 들어간다.

---

## 2. 분류 체계 (측정 전 확정, 사후 변경 금지)

| # | 분류 | 정상화 적절성 |
|---|---|---|
| **a** | **실질 부재 / 전액 상각완료** — 유한내용연수 무형자산이 없거나 장부가 0 | ❌ 정당한 부재 |
| **b** | **다른 곳 기재** — 순액이 본문·다른 태그로 공시됨(우리 태그 목록 밖 포함) | ❌ 이중계상 |
| **c** | **ASC 350 유한내용연수 무형자산이 아님** — 업종 특수 개념의 동음이의 | ❌ 부적절 |
| **d** | **진짜 누락** — 유한내용연수 무형자산이 실재하는데 순액이 어디에도 없음 | ✅ **표적** |

**c의 사전 지정 후보** (스파이크3-V의 업종 동음이의 교훈 선반영):
- **REIT(SIC 6798)**: 부동산 취득 시 배분되는 **in-place lease / above·below-market lease
  intangible** — ASC 805 배분액이지 ASC 350 무형자산 관리 대상과 성격이 다름
- **보험(SIC 641x·631x)**: **DAC(이연신계약비)**·**VOBA** 등 보험 특수 계정
- **광업(SIC 1000)**: **광권·탐사평가자산**

**대상 26건 중 REIT 4·보험 3·광업 2** — c 후보가 이미 **9건(35%)**이다.

## 3. 검증 절차

1. SEC `primaryDocument` 기준 10-K 본문 취득(첨부문서 금지 — 스파이크2에서 실제로 밟은 오류)
2. 무형자산 관련 진술 전수 추출: 순액 금액 · 상각 스케줄 · "fully amortized" · 업종 특수 용어
3. §2 4갈래로 판정하고 **근거를 원문 그대로 인용**(배제리스트 이유 줄에 인용 가능해야 — Sally 조건)
4. 같은 회사가 여러 분기에 걸치면 **최신 결산 1건**만 판정

## 4. kill criteria (측정 전 확정)

| # | 기준 | 미달 시 |
|---|---|---|
| **W1** | **d ≥ 1곳** | 무형자산 개념도 **스크리너에서 제외**. 세 개념 전멸 확정 |

비율 임계는 두지 않는다(파티 결정 ① 계승). 다만 **관측 비율은 그대로 보고**한다.

## 5. 사전 예측 (사후 대조용, 정의 아님)

| # | 예측 | 근거 |
|---|---|---|
| P1 | **c가 30% 이상** | REIT·보험·광업이 이미 35%를 차지 |
| P2 | **b가 존재할 것** — 우리 태그 목록 밖 공시 | T5에서 umbrella 태그를 놓친 전례. 목록은 또 불완전할 수 있다 |
| P3 | **d는 0 또는 1** | 리스·SBC 모두 0이었다 |
| P4 | **대기업(Sturm Ruger·PGE·MPW·Brixmor·Erie)은 전부 b 또는 c** | 자기점검 규칙 2연속 적중 — 3연속을 예측한다 |

**P1~P4가 틀려도 §2 분류와 §4 기준은 바꾸지 않는다.**

**탐색적**으로 강등한다.
