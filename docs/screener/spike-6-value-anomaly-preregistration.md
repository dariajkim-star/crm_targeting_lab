# Spike 6 · 사전등록 — C′ 가설: peer 대비 값 이상치 탐지 (왜곡 탐지)

- **일자**: 2026-07-31
- **성격**: **사전등록 문서.** 측정 전에 작성·커밋한다(스파이크2·3-V·4·5 방식 계승).
- **지위**: daria 판정 "1안(정본 회귀 + C′ 합성)" (2026-07-31, C안 재검토 파티)의 실행 1단계.
  §5 kill criteria는 이 커밋으로 고정되며, **측정 시작 후에는 수정 불가.**
- **복명복창**: 표준 XBRL 금액이 안 잡히는 회사를 ①진짜 누락 ②다른 곳 기재 ③애초에 0으로
  구분하고, **정상화하면 기업가치·재무비율·투자자 판단이 달라지는가**에 답한다.

---

## 1. 가설 (C′)

**결함은 부재가 아니라 "있는데 틀린 값"에 산다** — 스파이크5 수렴 실측(확정 결함 19곳 중
태그 부재 2곳뿐). 그렇다면:

> **H(C′)**: 표준 태그 값의 **peer 분포 대비 위치**(거리)로, 제3자/자사가 확인한 값 왜곡을
> 사전에 지목할 수 있다.

- 이 가설이 통과하면 스크리너의 표적이 "부재 탐지"에서 **"부재 3분류(정본 1차 산출물, 확정) +
  값 왜곡 검증 우선순위(C′, 신규 2차)"**로 확장된다.
- 통과하지 못하면 C′는 기각되고, 프로젝트는 정본 회귀(3분류 테이블 + ① 희소성 실측 라벨)로
  마감 후보가 된다.

## 2. 왜 지금 이 스파이크인가

스파이크5가 남긴 자산: **왜곡형 확정 결함 15곳**(`data/spike5-adjudication.json`의
misstatement 트랙 — 8-K Item 4.02로 자사가 값 오류를 인정, 대상 연차·개념 특정 완료).
부재 탐지의 X2에서는 비산입 라벨이었지만, **왜곡 탐지의 양성 대조군으로는 완전체다.**
양성 대조군을 손에 쥔 상태로 시작하는 첫 스파이크 — 임계가 측정을 앞설 뿐 아니라
**대조군이 설계를 앞선다.**

## 3. 측정 설계

### 3-1. 표적 지표 (사전 고정 — 지표 쇼핑 금지)

각 양성 사례의 **원 제출본**(재작성 이전 10-K, accession 단위 — 스파이크5 §10-4 방식) XBRL에서:

```
scaled_value = 개념 태그 값 / 같은 제출본의 Assets(총자산)
peer_position = scaled_value의 peer 셀 내 백분위 (양측)
flag = peer_position < p5 OR peer_position > p95
```

- **개념 태그**: 리스 계열 = OperatingLeaseLiability(Current+Noncurrent 합산 허용) /
  무형 계열 = FiniteLivedIntangibleAssetsNet(부재 시 IntangibleAssetsNetExcludingGoodwill) /
  goodwill 계열 = Goodwill. 사례별 계열은 spike5-adjudication.json의 concept을 따른다.
- **스케일 축 = 총자산 단일.** 매출 스케일은 감도 annex로만 병기(crm 3-4 b′ 계약 — official
  판정에 비산입). 축을 결과 보고 고르는 것을 금지하기 위해 여기 박는다.
- **양측 검정.** 왜곡은 과대·과소 양방향이다(실측: 과대 Alpine 4·Plug Power / 과소 ADT 손상).
- **보정 없음(의도적).** T4의 경고 — 연속 신호에서 공변량 보정은 순위를 재배열해 사냥감을
  지울 수 있고 그 성질은 미검증이다 — 때문에 이 스파이크는 **원거리(raw distance)만** 잰다.
  보정 도입은 이 스파이크가 통과한 뒤의 별도 스토리이며, 그때 T4 연속판 회귀 테스트가 선행조건.

### 3-2. peer 셀 (기존 계약 상속)

SIC4, n≥10, 미달 시 SIC3 승급, 그래도 미달이면 **판정 불가**(측정 불가로 기록 — 억지 셀 금지).
peer 값의 출처는 **FSDS 분기 벌크**(adsh 단위 = 원 제출본 성질 보존). companyfacts·frames는
정정 병합본이라 **peer 쪽에도 쓰지 않는다**(스파이크5 §10-4 교훈의 일관 적용 — target만
원 제출본이고 peer가 병합본이면 비대칭 오염).

### 3-3. 대조군 2종

| 대조군 | 구성 | 목적 |
|---|---|---|
| **양성** (필수) | 왜곡형 15곳 × 해당 왜곡 연차의 원 제출본 | 민감도 |
| **음성** (필수) | 같은 기간·같은 peer 셀에서 무작위 추출 ≥100곳 (재작성 이력 무 — 8-K Item 4.02 전수 대조로 확인) | 오탐률. **이게 없으면 "전부 이상하다"로도 민감도가 나온다** |

### 3-4. 결과 해석의 한계 (측정 전 선언)

- **거리 ≠ 오류.** p95 밖이라는 것은 "peer와 다르다"이지 "틀렸다"가 아니다. 통과 시 출력은
  배제리스트가 아니라 **검증 우선순위 리스트**이며, 화면 문언은 "이 값은 peer 분포에서 이만큼
  떨어져 있고, 확인할 가치가 있다"로 고정한다(Sally 조항 — 레아 원칙의 C′ 판: 고의를 판정하지
  말고 **거리를 드러내라**).
- 왜곡의 **크기**가 flag 가능성을 지배할 것이다. 소액 왜곡(Polished $372K)은 원리상 안 잡힌다 —
  그것은 이 방법의 실패가 아니라 **해상도의 정직한 한계**이며, 민감도 해석 시 왜곡 크기 분포를
  병기한다.
- 양성 15곳은 **8-K 자인 사례**로의 선택 편향이 있다(발각된 왜곡 ≠ 전체 왜곡). 민감도는
  "자인된 왜곡에 대한" 민감도로만 읽는다.

## 4. 판정 지표

| 지표 | 정의 |
|---|---|
| **민감도** | 측정 가능한 양성 중 flag된 비율 |
| **오탐률** | 음성 대조군 중 flag된 비율 (설계상 기대 기저율 ≈ 10%) |
| **lift** | 민감도 / 오탐률 |
| 왜곡 크기 대조 | flag된/안 된 양성의 왜곡 금액 상대 크기 (해석 병기용) |

## 5. kill criteria (이 커밋으로 고정 — 측정 후 수정 불가)

| # | 기준 | 미달 시 |
|---|---|---|
| **Y1** | 양성 15곳 중 **측정 가능 ≥ 8곳** (원 제출본 태그 존재 ∧ Assets 존재 ∧ peer 셀 성립) | **검증 불가**를 기록하고 C′ 판정 유보 — 스파이크5 X1 미달과 같은 정직 처리 |
| **Y2** | 민감도 **≥ 40%** | C′ 기각 — "왜곡은 peer 거리로 안 잡힌다"를 결론으로 기록 |
| **Y3** | 오탐률 **≤ 15%** ∧ lift **≥ 2.5** | Y2가 통과해도 **C′ 기각** — 전부 이상하다고 외치는 탐지기는 탐지기가 아니다 |

- 40%의 근거: 양측 p5/p95 설계의 기저 flag율 ≈ 10%에 대해 4배 lift. 절반도 못 잡는 탐지기를
  "작동한다"고 부르는 것은 X2(50%)보다 이미 관대한데, 왜곡 크기 분포의 하위권(소액)이 원리상
  탈락함을 감안한 보정이다. **결과를 보고 이 문단을 다시 쓰는 것을 금지한다.**
- 스파이크5의 부재형 2곳(Veroni·SS Innovations)은 이 측정에 **비산입** — 태그가 없어
  scaled_value가 정의되지 않는다. 별도 각주로만 기록.

## 6. 착수 순서

1. 양성 15곳의 원 제출본에서 개념 값·Assets 추출 (spike5 §10-4 방식 재사용,
   `scripts/spike5_x2_measure.py` 계보)
2. 해당 기간 FSDS 벌크에서 peer 셀 구성 (SIC4/n≥10/SIC3 승급)
3. 음성 대조군 추출 (≥100, 8-K Item 4.02 전수 대조)
4. flag 판정 → 민감도·오탐률·lift 산출 → Y1~Y3 판정
5. 결과를 THESIS §6(C′ 지위)·FINDINGS §7-1에 반영

## 7. 구속력

§3 설계 · §4 지표 · §5 kill criteria는 결과를 보고 수정하지 않는다. 수정이 필요하면 사유와
함께 별도 기록하고 그 측정은 **탐색적**으로 강등한다. 배관(plumbing) 정정은 §8 개정 이력에
기록하되 기준은 불변(스파이크5 §8 선례).
