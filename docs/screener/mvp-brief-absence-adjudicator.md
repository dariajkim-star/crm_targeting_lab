# MVP 브리프 — 부재 판정기 (Absence Adjudicator)

- **일자**: 2026-07-31 (마감 파티 익일 안건 — TRL 판정 파티)
- **지위**: 브리프. daria 비준 시 TRL 4 스토리(스캐폴딩)의 입력이 된다.
- **복명복창**: 표준 XBRL 금액이 안 잡히는 회사를 ①진짜 누락 ②다른 곳 기재 ③애초 0으로
  구분한다. (마감된 프로젝트의 정본 — MVP는 이 3분류 판정기의 제품화다)

---

## 1. TRL 판정 (파티 합의 2026-07-31)

**현위치 = TRL 3 (개념 실증 완료).** 스파이크 1~6이 실데이터 10-K 6,216건에서 3분류 분해를
끝까지 돌렸고, 가설의 생사가 사전등록 기준으로 판정됐다.

**빈칸과 순서**:

| 단계 | 빈칸 | 성격 |
|---|---|---|
| **TRL 4** | 스캐폴딩된 코드베이스 + 이식 계약 9건 테스트 고정 + 스파이크 골든 재현 | **의무** — 마감 문서가 "3분류 판정기"를 산출물로 선언했으나 실재는 흩어진 스크립트 6개·테스트 0건(그럼발 지적). 선언과 실재의 간극을 닫는다 |
| TRL 5~6 | MVP (이 브리프가 정의) | 정의 후 구현 |
| TRL 7 | 파일럿 — daria의 실제 종목 분석 워크플로 투입 | MVP 뒤 |

## 2. 제품 재정의 — 스크리너가 아니라 판정기

죽은 것: "워싱 기업을 걸러내는 그물"(전제 ① 다수 존재 — 실측 기각).
산 것: **"부재를 설명하는 도구."** 46곳 검증에서 ②③④⑥ 분류가 실증 작동했다.

> **한 줄 정의**: 애널리스트가 (회사, 재무 개념)을 넣으면 — *"왜 이 금액이 표준 XBRL에
> 없는가"*를 6형태 분류 + 근거 한 줄 + 확인 필요 수준으로 30초 안에 답하는 실사 보조 도구.

**사용자**: 크레딧/주식 애널리스트의 실사 장면. 첫 파일럿 사용자 = daria 본인 (John).
**아닌 것**: 배제리스트 생성기 · opacity_rank · 왜곡 탐지(C′ 기각) · 고의 판정(레아 원칙).

## 3. MVP 범위

### 3-1. 입력
- 회사 식별자(CIK 또는 티커) + **잔액형 개념** (리스 부채 · 무형자산 순액 · goodwill — 실증된 3계열)
- **흐름 개념은 입력 단계에서 거부** (⑤정당한 0은 기계 불가 — 스파이크2 실증, Boundary 조건)

### 3-2. 출력 (Sally 문언 계약)
- 6형태 판정: ①후보 / ②다른 곳(발견 태그 명시) / ③파생 소계 / ④해당 없음 / ⑥동음이의(업종 명시)
- **모든 판정에 근거 한 줄** (관측값 인용 — "notes 데이터셋에 IntangibleAssetsNetExcludingGoodwill $X 존재")
- ①은 "**진짜 누락 후보 — 10-K 확인 필요**"로만 출력. **"누락 확정"은 시스템이 낼 수 없는 문구**
  (탐지력 검증 불가 영구 단서의 제품 판)
- 머리말 고정: 판정기의 탐지력 한계 + peer 커버리지 맥락(동종 N곳 중 M곳 공시)

### 3-3. 내부 규칙 (전부 실증된 것만)
- 두 데이터셋 부재 계약 (face + notes 합집합 — T2)
- 파생 소계 검사 (Gross−Amort — T3-확장)
- 상위·병렬 태그 계열 목록 (성장 중 라벨 — Boundary 조건)
- ④판별: SIC 구성 + 증거 조건화 (T3)
- ⑥업종 배제 목록 (성장 중 라벨)
- peer 셀: SIC4 / n≥10 / SIC3 승급 / 미달 시 "판정 불가" (억지 셀 금지)

### 3-4. 인프라 계약 (이식 계약 9건 — 전부 테스트 고정)
- **데이터 계보·무결성 계약**: 행 단위 CIK–accession 필수, **404 ≠ 부재**(조회 실패 구분 —
  스파이크6 교훈), 상위 변경 시 하위 미재계산 = 테스트 실패
- 크래시 안전성: 원자적 쓰기 + **"몇 행 검사했나"** 완료 메타 (Sally 조항 — 4단계 게이트 3번)
- 나머지 7건: T6 §4 + THESIS 결정 대장 참조

### 3-5. 비범위 (명시)
- 전 종목 일괄 스크리닝(그물) — 죽은 전제의 부활 금지
- 왜곡 탐지 — C′ 기각. 유산 각주의 재검토 조건(본공연급 표본) 충족 전 금지
- DART — 후속 프로젝트 (단, 아키텍처는 데이터 소스 교체 가능하게 — Winston)

## 4. MVP 완성 기준 (TRL 5~6 판정 기준 — 착수 전 고정)

| # | 기준 |
|---|---|
| M1 | 스파이크 4의 무형자산 전수 23곳 판정을 **커밋된 코드 + 골든 테스트**로 재현 (비트 동일 아닌 판정 동일) |
| M2 | 이식 계약 9건이 각각 **죽일 수 있는 테스트**로 고정 (동어반복 금지 — crm 규율 계승) |
| M3 | 미학습 신규 회사 1곳(스파이크 표본 밖)에 대해 입력→출력 30초 내, 근거 한 줄 포함 |
| M4 | "누락 확정" 문구가 출력 불가능함을 테스트로 단언 (문서-계약 테스트 — crm 4-3 방식) |
