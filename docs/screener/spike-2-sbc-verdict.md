## 2. 탐색적(exploratory) 보정 — 사전등록 정의가 불완전했다

**개별 검증 과정에서 사전등록 태그 목록이 대체 공시를 놓쳤음이 드러났다.** 규약 §6에 따라
아래는 **확증이 아니라 탐색적 결과**로만 기록한다.

놓친 대체 태그(발견된 것만):
- `NonCashShareBasedCompensation` · `StockBasedCompensation` · `ShareBasedCompensationContinuingOperations` (동의어)
- `AllocatedShareBasedCompensationExpenseNetOfTax`
- `AdjustmentsToAdditionalPaidInCapitalShareBasedCompensation…RequisiteServicePeriodRecognitionValue`
  → **주주지분변동표에 적은 회사들.** 현금흐름표가 아니라 자본변동표에 인식액을 표시
- **`Sharebased…` (소문자 b) 대소문자 변형** — us-gaap 택소노미 자체의 표기 흔들림

탐색적 재측정: 잔차 **349 → 279**(20.1% 강등). **그리고 강등된 쪽에 대기업이 몰려 있었다** —

## 3. 🔴 S2 개별 검증 — 실제 10-K를 열었고, 생존자가 없다

잔차 중 증거가 강한 곳부터 **11곳의 10-K 본문을 직접 열람**했다(SEC `primaryDocument` 기준).

| 결과 | 곳 |
|---|---|
| **명시적 ZERO 진술** | Thunder Mountain Gold |
| **금액 0 확인**(임원보수표 전액 $0) | Worlds Inc |
| **정책 문구만, 금액 없음** | China Automotive · Ethema Health · Smithfield · PNC · Envela · Starwood Credit REIT |
| **본문 언급 자체 없음** | GBT Technologies · Escalon Medical · Harbor Diversified |
| **✅ 확인된 진짜 누락** | **0곳** |

결정적 문장 — Thunder Mountain Gold 10-K:

> *"Share-Based Payments: **No compensation expense from stock options was recognized** during the
> year ended December 31, 2024 and 2023."*

**옵션은 살아 있는데 당기 비용이 0이다.** XBRL은 0을 잘 태깅하지 않는다 → **태그 부재가 곧 완전한
공시**다. 숨긴 게 아니라 적을 금액이 없었던 것.

> 그리고 PNC·Envela·Smithfield는 전용 주석(`NOTE 15 - STOCK-BASED COMPENSATION` 등)을 갖고 있다 —
> **§2의 태그 누락이 아직 더 남아 있다는 뜻**이며, 이들도 진짜 누락이 아닐 가능성이 높다.

**S2 = "개별 검증을 통과한 실명 ≥ 1곳". 11곳을 열어 0곳.** 미달이다.

## 4. 왜 실패했나 — 이 스파이크의 진짜 소득

**주식보상은 '흐름(flow)'이고, 리스 부채·무형자산 순액은 '잔액(stock)'이다.**

| | 잔액 개념 (리스·무형) | **흐름 개념 (주식보상)** |
|---|---|---|
| 제도·자산이 존재하면 | 금액이 **반드시** 존재 | 당기 금액이 **0일 수 있다** |
| 따라서 "증거 있음 → 금액 있어야" | ✅ 성립 | ❌ **성립 안 함** |
| 태그 부재의 의미 | 미공시 의심 | **정당한 0일 수 있음** |

**사전등록한 '증거' 규칙(옵션 잔량·미인식원가 있으면 비용이 있어야 한다)이 흐름 개념에서
구조적으로 무효다.** 부여가 전부 가득(vest)됐으면 옵션은 남아 있고 비용은 0이다.

→ **스크리너 개념 선정 기준이 하나 생겼다: 잔액 개념을 우선하고, 흐름 개념은 "0이 정당한가"를
가릴 별도 장치 없이는 쓰지 않는다.**

## 6. 스크리너에 남기는 것

1. **개념 선정 기준(신규)**: **잔액 개념 우선.** 흐름 개념은 "정당한 0"을 가릴 장치가 없으면 채택 금지.
2. **"부재 ≠ 누락"의 다섯 번째 형태**: **정당한 0**. 앞선 넷(데이터셋 절단·파생 가능 소계·상위 태그·
   해당 없음)과 다른 종류다 — 값이 다른 데 있는 게 아니라 **값이 진짜로 0**이다.
3. **택소노미 대소문자 변형 주의**: `ShareBased` vs `Sharebased`. 태그 매칭은 대소문자 무시로.
4. **자기점검 규칙 재확인**: 대기업이 상위권이면 내 태그 목록을 먼저 의심한다. 2연속 적중.
5. **사전등록은 만능이 아니다**: 태그 목록이 불완전하면 사전등록해도 결과가 틀린다. 사전등록이
   막는 것은 **결과를 보고 기준을 고르는 것**이지 **처음부터 틀리는 것**이 아니다.
