# Tableau Public 퍼블리시 절차서 (4-4, FR18)

세션이 Tableau를 실행할 수 없으므로(conventions 7항) **이 문서는 daria가 실행한다**. 제작의 유일한
설계 출처는 `marts/dashboard-spec.md`(기계 검증된 계약면)이며, 이 절차서는 순서와 검증만 담는다.
소요 예상: 계정 보유 시 1~2시간.

> **공개 고지**: 퍼블리시하면 워크북에 연결된 `marts/mart_customers.csv`의 내용이
> **공개 조회 가능**해진다. 4-4 공개 점검이 전 컬럼의 공개 데이터셋(BankChurners) 유래를 확인했고,
> 커밋 이력에 data/model 아티팩트 유입 0건을 확인했다(스토리 4-4 Dev Record). 그래도 게시 전
> ③단계 검산을 건너뛰지 말 것.

## ⓪ Tableau Public 계정 (OQ-5)

- [ ] https://public.tableau.com 에서 계정 확인(없으면 무료 생성). Tableau Desktop Public Edition
      또는 웹 편집 중 편한 쪽을 쓴다.
- 어긋나면: 조직 계정/라이선스 문제는 이 프로젝트와 무관 — 개인 무료 계정이면 충분하다.

## ① 데이터 연결

- [ ] 새 워크북 → 텍스트 파일 원본으로 `marts/mart_customers.csv` 연결.
- [ ] 필드 타입 확인(10컬럼 전체 — "나머지"로 뭉개지 않는다):
      정수 = `CLIENTNUM`·`segment_id`·`target_priority` /
      문자열 = `quadrant_official` /
      실수 = `customer_value`·`churn_score`·`churn_prob_calibrated`·`threshold_official_risk`·`threshold_official_value`·`expected_saving`.
- [ ] **`churn_score` 필드 숨김(hide)** — 사양서 숨김 필드 절. 필드 목록에 보이면 안 된다.
- 어긋나면: 행수가 10,127이 아니면 파일이 아니라 **연결·필터**를 의심(마트는 결정론).

## ② 워크북 제작

- [ ] `marts/dashboard-spec.md`의 탭 구성(공식 4탭 + 시나리오 탭5)·시트·필드 매핑·캡션 규약을
      **그대로** 따른다. 사양서에 없는 계산필드를 만들지 않는다(금지 조항 3종).
- [ ] **탭4(LTV 동결 스텁)**: 데이터 연결 없이 빈 대시보드에 텍스트 1개만 — "epic-2 동결로
      데이터 부재, 4-2 해동 시 작성"(사양서 스텁 절 문구). 없는 데이터로 시트를 만들지 않는다.
- [ ] 시나리오 탭5 파라미터 `[budget]`: 정수·기본 2,500·**허용 값 = 범위(range) 모드, 최소 0·
      단계 500, 임의 타이핑 입력 비활성** — 이 설정이 Python `select_within_budget`과의 동치를
      보장한다(사양서 정직 각주: 5의 배수 정수를 벗어나면 경계 예산에서 1명 괴리 가능).
- [ ] **`budget=0` 캡션**: "예산 0 = 빈 캠페인(선택 0명이 정상)" 캡션을 시트에 부착(사양서 규정).
- [ ] 탭3 요인·액션 캡션: 경고 2문구("…인과가 아니다" / "실측 아닌 제안") 병기 — 미병기는 사양 위반.
- 어긋나면: 만들려는 계산필드가 사양서에 없다면 **만들지 말고 멈춘다** — 필요해 보이는 필드가
      사양에 없는 것은 사양 결함이므로 세션 소환이 맞다(즉석 발명 금지, AD-3).

## ③ 검산 앵커 대조 (필수 — 건너뛰기 금지)

- [ ] `marts/dashboard-spec.md` **「검산 앵커」 표**와 화면 수치를 대조한다(수치 사본을 여기 두지
      않는다 — 사양서 표가 단일 대조 기준이고, 그 표는 pytest 골든과 동시 갱신 계약이다).
- [ ] **표기는 무시하고 값만 대조**: CSV·Tableau는 소수 6자리(`3899.000000`)로, 문서는 천단위
      콤마(`3,899`)로 표기한다 — 같은 값이다. 총합은 부동소수 집계 특성상 **±1 이내면 일치**로
      판정한다.
- 어긋나면(±1 초과): 워크북 필터·집계 설정을 의심하라. 마트가 틀렸다고 판단되면 게시 중단 후
      세션 소환(`pytest tests/marts`가 green이면 마트는 무죄다).
