## 3. 잘된 것

1. **바이트 불변 DoD** — "순수 경화"·"읽기 전용 소비자"를 스토리 설계에 박자, 리뷰 4사이클의 공격성에도 마트가 1바이트도 안 움직였다. 아티팩트 안정성과 리뷰 강도가 양립 가능함을 실증.
2. **3레이어+파티 리뷰의 타율** — 매 스토리 실질 Major/High를 잡았고(rename 우회, AD-3 ② 위반, quotepath false-green, 테스트 수 자기-stale), 오탐 기각도 정확했다(B5, E5, E15 등).
3. **인계 부채 청산 구조** — deferred-work 종결 주석 + sprint-status 액션 추적이 실제로 작동. 에픽1부터 끌어온 부채(1-2 호출부 재가중)까지 전부 닫힘.
4. **blocked-external 분업 설계**(P1 3-3 계승) — 세션 몫/daria 몫 경계가 done 판정을 흔들지 않았다.
